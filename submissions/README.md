# Assignment Submissions

Welcome. This folder is dedicated to student submissions.

## How to Submit

1. Fork this repository to your GitHub account.
2. Navigate to the `submissions/` folder.
3. Create a folder with your exact GitHub username.
4. Place each assignment inside its own folder.
5. Commit and push your changes.
6. Open a pull request to this repository.

Example:

```text
submissions/
└── sharafdin/
    ├── assignment-1/
    │   └── answers.md
    ├── assignment-4/
    │   └── spam_classifier.ipynb
    └── final_project/
        ├── project-proposal.md
        ├── project_paper.md
        └── README.md
```

## Rules

- Your folder name must exactly match your GitHub username.
- Only edit your own folder.
- Do not modify or delete another student's work.
- Keep code, notebooks, reports, and screenshots inside your own submission folder.
- Pull request title format: `Assignment Submission - <Your GitHub Username>`.
