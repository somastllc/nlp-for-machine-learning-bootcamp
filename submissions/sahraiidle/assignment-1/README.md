# Assignment 1: NLP Foundations

This assignment covers the basic foundations of Natural Language Processing (NLP).

## What We Learned

- What NLP is and how it relates to AI and Machine Learning
- Basic NLP terms such as corpus, document, token, vocabulary, feature, and label
- Common NLP tasks:
  - Text classification
  - Sequence labeling
  - Search and similarity
  - Text generation
- The difference between supervised and unsupervised learning
- Why text needs to be converted into numerical representations
- Bag of Words and its limitations
- Challenges of NLP for low-resource languages, especially Somali
- A case study on Somali-English machine translation

## Goal

The main goal of this assignment was to understand the core concepts of NLP and how they are applied to real-world language problems.
