# Lesson 2: Text Preprocessing

This lesson focuses on how to prepare raw text for NLP systems.

## What We Learned

- Text preprocessing and normalization
- Lowercasing and whitespace normalization
- Tokenization and different types of tokenizers
- Punctuation, URLs, numbers, emojis, and abbreviations
- Stopword removal and negation
- Stemming vs. lemmatization
- Regular expressions (regex) for text cleaning
- POS tagging and Named Entity Recognition (NER)
- Why preprocessing depends on the NLP task
- Using consistent preprocessing during training and inference

## Practical Work

We also practiced these concepts using Python and NLTK through the lesson's preprocessing script.

## Goal

The main goal was to understand how different preprocessing choices affect NLP data and why text should be cleaned carefully rather than automatically.
