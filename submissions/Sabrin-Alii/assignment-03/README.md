# Assignment 3 – Text Vectorization

## Overview
This assignment focuses on text vectorization and how text is converted into numerical features for Machine Learning models.

## Topics Covered
- One-Hot Encoding
- Bag of Words (BoW)
- Document-Term Matrix (DTM)
- Tokens and Vocabulary
- Text Preprocessing
- N-grams
- TF-IDF
- Fit, Transform, and Fit-Transform
- Data Leakage
- Cosine Similarity
- Limitations of Text Vectorization



## Files
- `answers.md` – Part A research answers and Part B practical report.
- `vectorization_practice.py` – Python script containing the 12 practical tasks.
- `output.txt` – Complete output generated by running the Python script.



This assignment demonstrates practical understanding of text vectorization techniques and their use in Natural Language Processing.
