# Assignment 2 – Text Preprocessing

This assignment focuses on text preprocessing techniques used in Natural Language Processing (NLP).

It includes:

- Text normalization and cleaning
- Tokenization and stopword removal
- Stemming and lemmatization
- Sentence splitting and Named Entity Recognition (NER)
- Practical exercises using Python and NLTK

## Files

- `answers.md` – Research answers and practical report.
- `preprocessing_practice.py` – Python practical code.
- `output.txt` – Output generated by running the Python script.

**Tools:** Python, NLTK, and Regular Expressions (Regex).
