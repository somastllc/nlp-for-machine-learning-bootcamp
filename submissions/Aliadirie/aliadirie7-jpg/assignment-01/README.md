# NLP Foundations – Assignment 1

## About
This repository contains my answers to Assignment 1 – NLP Foundations. The assignment introduces the fundamental concepts of Natural Language Processing (NLP), its relationship with Artificial Intelligence and Machine Learning, common NLP tasks, learning approaches, text representation, and challenges in low-resource languages such as Somali.

## Assignment Topics
1. Introduction to Natural Language Processing
2. NLP Core Terminology
3. Common NLP Tasks
4. Supervised and Unsupervised Learning
5. Text Representation
6. Challenges of NLP for Low-Resource Languages
7. Somali Sentiment Analysis Case Study
