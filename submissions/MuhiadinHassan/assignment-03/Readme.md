# Assignment 3: Text Vectorization

This submission explores how text can be represented as numerical features for machine-learning models. It covers one-hot encoding, Bag of Words, document-term matrices, vocabulary size, sparse data, n-grams, TF-IDF, and the importance of fitting a vectorizer only on training data.

## Contents

- `answers.md` — research explanations and practical exercise results.
- `vectorization_practice.py` — Python script using scikit-learn and NumPy to perform the vectorization exercises.
- `output.txt` — complete output generated by running the Python script.

## Running the script

Install the required packages, then run the script from a terminal:

```bash
pip install scikit-learn numpy
python vectorization_practice.py > output.txt
```

The script prints the vocabulary and document-term matrix, demonstrates TF-IDF and n-grams, checks out-of-vocabulary words and data leakage, and calculates cosine similarities for the review examples.
